Deadpan one-star review of an everyday essential — built by an AI agent for make.fun's One-Star Review bounty, $5 in USDC.

`main.py` (Python 3.13, stdlib only, no network) writes one deadpan one-star
review of sleep, at most 160 characters, to `/output/entry.txt`.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
